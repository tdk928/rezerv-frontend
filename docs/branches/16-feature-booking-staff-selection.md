# feature/booking-staff-selection

## Цел
При резервация клиентът да избира точно един конкретен свободен служител.

## Направено
- След избор на час винаги се показва списък с наличните служители.
- При един служител той се маркира автоматично и повторен клик не го отмаркира.
- При няколко служители няма предварителен избор; показва се validation и бутонът
  за потвърждение е disabled до избора на точно един.
- Изборът е single-select (`radiogroup`) и `staffId` се изпраща към booking API.
- Добавени UI тестове за one-staff и multi-staff сценариите.

## Решения
- Списъкът е част от избрания slot response; няма допълнителна API заявка.
- Single-select state е `number | null`, което не допуска повече от един избор.

## Как се тества
```bash
npm test -- --run src/pages/BookAppointmentPage.test.tsx
npm run build
```

Ръчно: отвори `/salons/{id}/book?serviceId={id}`, избери дата и час, след което
провери автоматичния или ръчния избор на служител.
